# Complete installer

Fixes the missing **Tags** context menu after installing ColorTags on another
computer. The 1.0.0 EXE installed only the visual overlay. This installer also
registers the menu and Tags column.

- Bundles Python 3.14.7 and a signed MSIX. No separate Python or Windows SDK
  installation is needed, and setup does not download dependencies.
- Reports registration errors and saves details to
  `%LOCALAPPDATA%\Colortags\setup-integration.log`.
- Uninstall removes Explorer integration and certificates added by setup.
- Preserves existing file tags, custom labels and display preferences.

Download **ColorTags-Setup-1.0.1.exe** and run it over the existing installation.
Approve the administrator prompts for the package certificate and column
registration. Reopen Explorer or sign out and back in if it retains the old menu.
The EXE is unsigned; the menu MSIX uses a self-signed certificate. Managed
devices may require their administrator to allow this package.

The ZIP is an alternative for manual registration and includes the same runtime.
Scrolling behavior is unchanged in this release.

Validation: 75 core tests, native property/menu/icon smoke, isolated runtime
tagging and signature checks, and install/repair/uninstall smoke on Windows CI.
