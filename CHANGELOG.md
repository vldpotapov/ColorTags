# Изменения

## v1.0.0 — первый публичный выпуск

- Англоязычный установщик внешнего слоя с фирменным изображением и значком.
- При обновлении установщик завершает работающий слой через его событие;
  Windows предлагает закрыть приложение, если его файл всё ещё занят.
- ZIP теперь содержит Python-модули, необходимые контекстному меню, и
  регистрация работает после извлечения архива.
- Удалены устаревший прототип слоя и локальные пути/адреса из текущего дерева.
- Уточнены требования и ограничения установки в README и INSTALL.md.

## v0.3.0

- Иконка приложения: окно, панель задач, значок в трее, установщик и логотипы
  пакета берут её из `assets/app-icon.svg`.

- В заголовке окна настроек показывается версия, а в карточке About — проверка
  обновлений: один запрос к странице релизов GitHub при открытии окна и по
  кнопке «Check now», кнопка «Releases» открывает страницу релизов. В фоне, пока
  слой просто работает, в сеть программа не ходит.
- Кнопки в карточке About стоят в столбик, чтобы строка состояния помещалась
  целиком; если проверка не прошла, в скобках показывается код ошибки WinHTTP
  или HTTP-статус. Меню в трее и подсказка значка называют программу и версию.
- Включённые тумблеры и кнопка OK стали темнее, у кнопок появился подсвет при
  наведении.

- Переключение режима показа обновляет открытые окна Проводника: он кеширует
  значение колонки за каждым элементом, поэтому после смены режима под кружками
  оставались названия тегов, показанные до переключения.

## v0.2.0

**Установщик и выпуск**
- Добавлен per-user установщик Inno Setup для внешнего слоя: без UAC, с ярлыком,
  необязательным автозапуском и обычным удалением через настройки Windows.
- GitHub Actions теперь прикладывает к релизу как полный ZIP-пакет, так и
  `ColorTags-Setup-*.exe`.
- Скрипты запуска и остановки корректно работают с установленной копией и
  завершают оверлей через именованное событие.

**Исправления**
- Кружки остаются видимыми во всех открытых окнах Проводника, включая фоновые,
  и располагаются над своим окном.
- Исправлены случаи, когда пустая область отсечения скрывала весь слой.
- Колонка Tags не выводит текст под цветным кружком в режиме внешнего слоя.
- Назначение и снятие тега сохраняют исходные времена файла.
- Нативный оверлей собирается как GUI-приложение и не открывает окно консоли.
- Регистрация расширения надёжнее находит утилиты подписи Windows SDK.

## v0.1.0

Первый релиз.

**Теги**
- Цветные теги для файлов и папок: red, orange, yellow, green, blue, purple, gray.
- Тег хранится в альтернативном потоке NTFS `:ColorTag` рядом с самим файлом —
  ничего не переносится и не индексируется отдельно; для носителей без NTFS есть
  запасное хранилище SQLite.
- Названия тегов переименовываются, идентификаторы в потоке остаются прежними,
  поэтому переименование ничего не ломает.

**Проводник**
- Пункт в контекстном меню (`IExplorerCommand`) — назначить или снять тег.
- Колонка `Tags` через обработчик свойств (`System.Keywords`).
- Значки-оверлеи поверх иконок (необязательно, Windows даёт на всю систему
  только 15 слотов).

**Внешний слой**
- Кружок или подпись с названием тега поверх строк Проводника, с привязкой к
  активной вкладке.
- Значок в трее и окно настроек: названия всех тегов, режим показа, поведение
  при прокрутке.

**Установка**
- Установщик для внешнего слоя: ставится в профиль пользователя, без прав
  администратора, с ярлыком и необязательным автозапуском.
- Расширение оболочки регистрируется отдельно; скрипт сам находит подписывающие
  утилиты Windows SDK.

**Поведение**
- Назначение и снятие тега не меняют «Дату изменения» файла: время снимается до
  записи потока и возвращается после.
- В режиме кружка колонка Tags остаётся пустой — иначе название тега просвечивало
  из-под диска.
- Слой держится во всех окнах Проводника, активных и фоновых, и стоит ровно над
  своим окном; на другом виртуальном рабочем столе не показывается.

**Известные ограничения**
- Бинарники не подписаны — SmartScreen предупредит при первом запуске.
- Регистрация расширения оболочки требует прав администратора и Windows SDK
  (makeappx, signtool).
- Внешний слой рисуется отдельным окном поверх Проводника: при прокрутке и
  перетаскивании окна он не синхронизирован по кадрам с содержимым.
- В папке с группировкой (например по дате) индикаторы могут вставать не на свои
  строки: заголовки групп нарушают равномерный шаг строк.
